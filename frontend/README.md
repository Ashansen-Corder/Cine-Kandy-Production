# Cine Kandy Films - Frontend

React.js frontend for Cine Kandy Films website.

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

## Build for Production

```bash
npm run build
```

## Features

- React 18 with Hooks
- React Router for navigation
- Framer Motion animations
- Responsive design
- Admin panel
- Gallery with lightbox
- Blog system
- Contact forms

## Tech Stack

- React.js
- React Router DOM
- Framer Motion
- Axios
- Lucide React (icons)
- CSS3 with CSS Variables
